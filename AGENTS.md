## Operating Model

1. **Curricula** live in `curricula/`
2. **Scenarios** live in `scenarios/`
3. **Evaluation criteria** co-located with scenarios
4. **Changes via PRs** — all contributions reviewed

## Branch Strategy

- `main` — stable, released curricula
- `feature/*` — new curricula or scenarios
- `docs/*` — documentation improvements

## Quality Standards

- Every scenario needs: prompt, context, options, evaluation criteria, example reasoning
- Curricula need learning objectives and assessment methods
- All content must be OSI-approved or clearly licensed
